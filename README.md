# searchparts

Накопительная база знаний помощника по подбору автозапчастей и работе с поставщиками в ОАЭ.
Репозиторий читается в начале каждой сессии и обновляется после каждой работы.

## С чего начать новую сессию

1. [`knowledge/rules.md`](knowledge/rules.md) — постоянные правила работы (подбор, фото, база контактов, формат ответа).
2. [`knowledge/lessons.md`](knowledge/lessons.md) — уроки и типовые ошибки, которые уже встречались.
3. [`knowledge/contacts-base.md`](knowledge/contacts-base.md) — как устроена и как обрабатывается база визиток поставщиков.
4. [`knowledge/sessions/`](knowledge/sessions/) — журнал сессий: что сделано, что осталось.

## Структура

| Путь | Что внутри |
|---|---|
| `knowledge/rules.md` | Правила пользователя для подбора деталей и работы с базой |
| `knowledge/lessons.md` | Накопленные уроки: что работает, где ошибались, чего не делать |
| `knowledge/contacts-base.md` | Схема базы контактов, ID, флаги, порядок пополнения и сверки |
| `knowledge/sessions/` | Короткие записи по каждой сессии |
| `tools/contacts/` | Скрипты: загрузка папки Drive, HEIC→JPEG, нарезка позиций, лупа, слепая сверка, применение правок к JSON и XLSX |

## Конфиденциальность

Репозиторий **публичный**. Сама база (телефоны, имена, email людей с визиток), фото визиток и ссылка на папку Drive
сюда не кладутся. Они хранятся в Google Drive пользователя (`UAE_Contacts.xlsx`, `UAE_Contacts_AI.json`).
Здесь — только методика, правила, инструменты и обезличенные итоги.
