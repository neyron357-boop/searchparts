## Дополнительно для Claude Code

- Облачное окружение `searchparts` имеет полный доступ в интернет (каталоги, схемы, фото деталей, публичные
  папки Drive). Записи в Drive нет — файлы отдавать пользователю. Защиту сайтов от ботов не обходить.
- Фото визиток: `pip install pillow-heif` (HEIC), лупа — `tools/contacts/zoom.py`, `zoomx.py`.
- Слепая сверка — субагентами по `tools/contacts/BRIEF_blind_read.md`, по 10 фото на агента, вывод писать
  пошагово (прерывание пользователем останавливает фоновых агентов).
- Рабочие файлы сессии — в scratchpad, не в репозитории.
- После каждой работы — раздел «Finish» из `AGENTS.md`, включая перенос в `main` (разрешено пользователем).
